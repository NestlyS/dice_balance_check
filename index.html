Проверка дисбаланса кубика

Выберите тип кубика, введите результаты бросков, редактируйте/удаляйте значения — и смотрите распределение выпадений по граням. Можно сохранять наборы в localStorage и загружать их позже.

Ввод данных

Кубик: d20

Подсказка: можно быстро вводить значения и нажимать Enter.

Статус: готово к вводу.
Данные сохраняются только в вашем браузере (localStorage). Очистка данных браузера удалит наборы.

# Значение Действия

Во время редактирования текущее значение скрывается и показывается в плейсхолдере поля ввода.

Диаграмма выпадений

Бросков: 0
Ожидаемо: равномерно по всем граням
Совет: чем больше бросков, тем надёжнее выводы.
Пунктир — ожидаемое количество выпадений на грань. Столбики показывают фактическое число выпадений.

Сводка (χ² тест равномерности)

df: 19
Итого: 0 бросков.
Ожидаемое значение на грань: —
χ²: —
p-value: —
p-value — вероятность (при “честном” кубике) получить отклонение от равномерности не меньше наблюдаемого. Малое p-value означает: “такое распределение маловероятно, если кубик честный”.
Пороговые подсказки (эвристика)
— p ≥ 0.10: отклонение выглядит нормальным для случайности
— 0.05 ≤ p < 0.10: слабые признаки отклонения
— 0.01 ≤ p < 0.05: есть основания подозревать дисбаланс
— p < 0.01: сильные основания подозревать дисбаланс
Важно про применимость
χ² приближение обычно “нормально” работает, когда ожидаемое число на грань E не слишком маленькое (часто используют правило E ≥ 5). Если бросков мало, тест может вводить в заблуждение.

Это статистическая подсказка, не “приговор”: дисбаланс могут имитировать малое число бросков, техника броска, поверхность и т.п.
